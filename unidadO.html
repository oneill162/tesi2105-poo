predecir(6.5, 3.0), paso a paso

string predecir(double diametro, double color) const override {
    double mejor = 1e9;
    string respuesta = "?";
    for (const Ejemplo& e : memoria) {
        double dx = e.diametro - diametro;
        double dy = e.color - color;
        double distancia = sqrt(dx * dx + dy * dy);
        if (distancia < mejor) {
            mejor = distancia;
            respuesta = e.etiqueta;
        }
    }
    return respuesta;
}

Dos modelos, una interfaz: polimorfismo

class Centroide : public Modelo {
    double dChina = 0, cChina = 0, dLimon = 0, cLimon = 0;
public:
    void entrenar(const vector<Ejemplo>& datos) override {
        // (12 lineas: promedia diametro y color de cada etiqueta)
    }
    string predecir(double diametro, double color) const override {
        double aChina = hypot(dChina - diametro, cChina - color);
        double aLimon = hypot(dLimon - diametro, cLimon - color);
        return aChina < aLimon ? "china" : "limon";
    }
    string nombre() const override { return "Centroide"; }
};

int aciertos(const Modelo& m, const vector<Ejemplo>& prueba) {

Cinco errores con la interfaz Modelo

Una clase abstracta es un contrato, no un objeto.

Se crean objetos de las clases hijas: VecinoCercano vecino;

class Adivino : public Modelo {
    ...
    string predecir(double, double) override { return "china"; }
};
error: 'std::string Adivino::predecir(double, double)' marked 'override', but does not override

La firma debe ser idéntica, incluido el const.

override es el que avisa: sin él, sería otra función y el error saldría más tarde.

Privacidad: pedir solo lo necesario

El formulario para prestar el robot del laboratorio. Marque los datos que de verdad necesita.

Cada dato que se guarda es un dato que se puede filtrar, perder o usar para otra cosa.

  • Minimización: se recoge solo lo que el propósito necesita.
  • Propósito y aviso: la persona sabe qué se recoge y para qué; si hace falta, da su consentimiento.
  • Seguridad y tiempo: se protege y se borra cuando ya no hace falta.

Un modelo es un objeto

Una interfaz abstracta con entrenar() y predecir(); cada algoritmo es una clase hija. Así lo hacen las bibliotecas reales.

Ética desde el diseño

Pedir solo los datos necesarios, medir por grupo para hallar sesgos, poder explicar cada respuesta y dejar a una persona a cargo.
