Tres errores con funciones

Mensajes reales de g++ 13.3.

int main() {
    cout << cuadrado(4);
}
int cuadrado(int x) { return x * x; }
error: 'cuadrado' was not declared in this scope

El compilador lee de arriba hacia abajo.

Cuando llega a main todavía no conoce cuadrado. Solución: declarar el prototipo antes de main.

int cuadrado(int x);   // prototipo

Con el prototipo compila e imprime 16.

int doble(int x) {
    int y = x * 2;
}
warning: no return statement in function returning non-void

Compila, pero quien llama recibe un valor indefinido.

Calcular y no contestar es colgar sin dar la respuesta. Falta return y;. g++ lo avisa con -Wall.

void saludar(string nombre) { ... }
cout << saludar("Ana");
error: no match for 'operator<<' (operand types are 'std::ostream' and 'void')

Una void no contesta nada que se pueda imprimir.

Se llama sola: saludar("Ana");. Si hace falta el valor, la función debe tener un tipo de retorno.

Funciones recursivas

Una función que se llama a sí misma, con un problema cada vez más pequeño.

EXT. 4 factorial(4) En espera: 3

Llamadas en espera: la pila

long long factorial(int n) {
    if (n <= 1)
        return 1;           // caso base
    return n * factorial(n - 1);
}

Pila de llamadas: arriba, la activa

Sin caso base, la llamada nunca termina

int sinBase(int n) {
    return n + sinBase(n - 1);
}
$ g++ -Wall rec.cpp -o rec warning: infinite recursion detected [-Winfinite-recursion] $ ./rec Segmentation fault

Cada llamada ocupa espacio en la pila hasta que se acaba la memoria.

Toda función recursiva necesita dos partes: un caso base que contesta sin llamar a nadie, y una llamada con un problema más pequeño que se acerca a ese caso.

Verificado con g++ 13.3 sin optimización. Dato: 20! = 2432902008176640000 es el último factorial que cabe en long long.

// #include <iostream>, <iomanip>, <cmath>, <string>
double promedio(double a, double b, double c) {
    return (a + b + c) / 3;
}
char letra(double p) {
    if (p >= 90) return 'A';
    if (p >= 80) return 'B';
    if (p >= 70) return 'C';
    if (p >= 60) return 'D';
    return 'F';
}
void reporte(string nombre, double p) {
    cout << nombre << ": " << fixed << setprecision(1)
         << p << " (" << letra(round(p)) << ")" << endl;
}
int main() {
    string nombre; double p1, p2, p3;
    cin >> nombre >> p1 >> p2 >> p3;
    reporte(nombre, promedio(p1, p2, p3));
}

Lo que se lleva de esta unidad

void

Hace un trabajo y no contesta. Se llama sola, en su propia línea.

Con retorno

return contesta con un valor del tipo declarado, que se puede guardar o usar.

Biblioteca

Incluir la cabecera correcta: <cmath>, <cctype>, <string>.

Recursivas

Caso base y un problema más pequeño en cada llamada. Sin caso base, la pila se desborda.

Los parámetros reciben copias, y una función se declara antes de usarla.
