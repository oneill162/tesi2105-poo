Punteros

En el correo, cada apartado tiene un número. Un puntero no guarda la carta: guarda el número del apartado donde está.

Concepto de punteros

La memoria es una pared de apartados numerados. Cada variable vive en uno.

p = 0x1004

«Su carta está en el apartado 1004.»

Un puntero guarda una dirección

Cada casilla tiene su número (la dirección, arriba) y lo que guarda (abajo). p no guarda 20: guarda dónde está el 20.

Las direcciones del dibujo son de ejemplo. Las reales las asigna el sistema, cambian en cada ejecución y se ven como 0x7ffe49949ca0.

& pregunta dónde; * pregunta qué hay

int edad = 20;
int* p = &edad;
cout << edad;20

Declaración de punteros

El asterisco en la declaración dice: esta variable guarda direcciones de un tipo.

int* p = nullptr;

tipo* nombre;

DeclaraciónSe lee
int* p;p apunta a un int
double* q;q apunta a un double
char* c;c apunta a un char
int* p = nullptr;p no apunta a nada todavía

Inicialice siempre el puntero. Si todavía no tiene a dónde apuntar, use nullptr.

El tipo tiene que coincidir con el de la variable:

double precio = 9.75;
int* p = &precio;
error: cannot convert 'double*' to 'int*'
in initialization

Todo puntero ocupa lo mismo, sin importar el tipo: sizeof(p) da 8 en una computadora de 64 bits.

Cambiar una variable sin usar su nombre

int edad = 20;
int* p = &edad;    // la direccion de edad
cout << "edad = " << edad << endl;
cout << "*p = " << *p << endl;
*p = 21;            // cambia edad

Punteros y arreglos

Un arreglo es una fila de apartados seguidos. Su nombre es el número del primero.

notas == &notas[0]

notas es la dirección de notas[0]

int notas[4] = {90, 85, 78, 92};
int* p = notas;        // lo mismo que &notas[0]
Las tres formas leen el mismo apartado

Aritmética de punteros

Sumarle 1 a un puntero es pasar al apartado siguiente, sea del tamaño que sea.

p + 1   // +4 bytes en int
        // +8 en double

p + 1 avanza un elemento, no un byte

El compilador multiplica por el tamaño del tipo. Cambie el tipo y avance.

Tipo:Avanzar:
Cálculo

Comprobado con g++: p + 1 avanza 4 bytes en int y 8 en double. La resta de dos punteros del mismo arreglo da elementos: (a + 2) - a es 2.

Solo lo que significa moverse por el arreglo

Válidas

p + n, p - navanzar o retroceder n elementos
p++, p--moverse uno a uno
p2 - p1distancia en elementos (mismo arreglo)
p < a + nsaber si se llegó al final

No compilan, o son peligrosas

p1 + p2sumar dos direcciones no significa nada
p * 2un puntero no se multiplica ni se divide

Punteros como parámetros

Darle a una función el número del apartado le permite cambiar lo que hay dentro.

duplicar(&n);

Solo el puntero cambia la variable de main

void duplicarValor(int x)    { x = x * 2; }
void duplicarPuntero(int* x) { *x = *x * 2; }
int n = 5;
duplicarValor(n);     // recibe una copia
cout << n << endl;    // 5
duplicarPuntero(&n);  // recibe la direccion
cout << n << endl;    // 10

En C++ moderno se prefiere la referencia cuando basta. El puntero se usa cuando hace falta lo que solo él puede hacer.

Paso de punteros a funciones

Un arreglo viaja a la función como el número de su primer apartado.

double promedio(
    const int* a, int n);

La función recibe la dirección y el tamaño

double promedio(const int* a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++)
        suma += *(a + i);
    return (double)suma / n;
}
int notas[4] = {90, 85, 78, 92};
cout << promedio(notas, 4);   // 86.25

const protege los datos

Con const int* a, la función puede leer el arreglo pero no cambiarlo. Si lo intenta:

a[0] = 0;
error: assignment of read-only location '* a'

Y necesita n: solo con la dirección del primer apartado, no sabe dónde termina la fila.

buscarMayor devuelve dónde está

int* buscarMayor(int* a, int n) {
    int* mayor = a;
    for (int* p = a + 1; p < a + n; p++)
        if (*p > *mayor) mayor = p;
    return mayor;
}
int* m = buscarMayor(notas, 4);
cout << *m << " en la posicion " << m - notas;

Para cambiar a dónde apunta un puntero de main

void marcarDestacado(int** destacado,
                     int* cant, int pos) {
    *destacado = cant + (pos - 1);
}
int* destacado = nullptr;
marcarDestacado(&destacado, cant, 2);
// ahora destacado apunta a cant[1]

Con int* la función cambia el dato. Con int** cambia el puntero mismo.

Es la parte D del Laboratorio E.

Lo verá otra vez en main(int argc, char** argv) y con los objetos que se crean con new en la Unidad H.

El compilador no siempre avisa

int* p = nullptr;
cout << *p;
Segmentation fault

Compila sin avisos y el programa se cae.

Antes de usar *p, compruebe if (p != nullptr).

int* p;
*p = 5;
warning: 'p' is used uninitialized [-Wuninitialized]

p apunta a cualquier lugar, y el 5 se escribe ahí.

Por eso se inicializa siempre, aunque sea con nullptr.

void duplicar(int* x) { *x *= 2; }
int n = 5;
duplicar(n);
error: invalid conversion from 'int' to 'int*' [-fpermissive]

La función pide una dirección y recibió un valor.

La llamada correcta es duplicar(&n);. El * lee o escribe el dato; el & da la dirección.

int notas[4] = {90, 85, 78, 92};
int* p = notas;
return *(p + 4);
g++ -Wall: warning: 'notas' is used uninitialized g++ -fsanitize=address: ERROR: AddressSanitizer: stack-buffer-overflow

-Wall da un aviso confuso; AddressSanitizer dice qué pasó.

Compile con -g -fsanitize=address cuando un programa con punteros falle sin explicación. Está en g++ de Linux y macOS; en Windows, use OnlineGDB o WSL.

Para intercambiar dos variables, ¿referencia o puntero?

Piensen en cómo se ve la llamada en main y en qué puede salir mal con cada una.

void swap(int* a, int* b)se llama con swap(&x, &y)
void swap(int& a, int& b)se llama con swap(x, y)la referencia: no puede ser nullptr y la llamada es más clara; el puntero, cuando hace falta moverse o «nada»

Lo que se lleva de esta unidad

& y *

&x da la dirección; *p da lo que hay allí. Inicialice con nullptr.

Aritmética

p + 1 avanza un elemento. p2 - p1 da la distancia en elementos.

Funciones

Con un puntero, la función cambia el original. Un arreglo llega como puntero y necesita su tamaño.
