Un puntero es una variable cuyo valor es una dirección de memoria. No guarda el dato: guarda dónde está el dato. Las direcciones del dibujo son de ejemplo; las reales las asigna el sistema y cambian en cada ejecución.

Tema 2 de 7

Declaración de punteros

Cómo se declara un puntero

tipo* nombre; El tipo dice a qué clase de dato apunta.

DeclaraciónSe lee
int* p;p apunta a un int
double* q;q apunta a un double
char* c;c apunta a un char
int* p = nullptr;p no apunta a nada todavía

Regla de oro: inicialice siempre el puntero. Si todavía no tiene a dónde apuntar, use nullptr.

El tipo tiene que coincidir:

double precio = 9.75;
int* p = &precio;
g++ diceerror: cannot convert 'double*' to 'int*' in initialization

Primer programa con un puntero

Tema 4 de 7

Aritmética de punteros

p + 1 avanza un elemento, no un byte

El compilador multiplica por el tamaño del tipo (sizeof). Cambie el tipo y avance.

Tipo:
▲ p
Cálculo

Comprobado en g++: p+1 avanza 4 bytes en int y 8 en double; fin - a da 3 elementos.

Qué operaciones se permiten

Solo las que tienen sentido como «moverse por el arreglo».

Válidas
p + n, p - nAvanzar o retroceder n elementos
p++, p--Mover el puntero uno a uno
p2 - p1Distancia en elementos (mismo arreglo)
p < a + nComparar para saber si llegó al final
No válidas o peligrosas
p1 + p2Sumar dos direcciones no significa nada
p * 2, p / 2Un puntero no se multiplica ni se divide
*(p + n) fueraPasarse del arreglo: comportamiento indefinido

Punteros como parámetros

Por valor contra por puntero

Solo el puntero deja que la función cambie la variable de main().

void duplicarPuntero(int* x) { *x = *x * 2; }

Tema 6 de 7

Paso de punteros a funciones

Un arreglo viaja a la función como un puntero

La función recibe la dirección del primer elemento; por eso necesita también n.

double promedio(const int* a, int n) {
    int suma = 0;
    for (int i = 0; i < n; i++)
        suma += *(a + i);
    return (double)suma / n;
}

promedio(notas, 4);    // 86.25

const protege los datos

const int* a: la función puede leer el arreglo, pero no cambiarlo.

Si lo intenta, g++ lo detiene:

a[0] = 0;
g++ diceerror: assignment of read-only location '* a'

Una función también puede devolver un puntero

buscarMayor devuelve dónde está el mayor, no solo cuánto vale. Siga el recorrido.

int* buscarMayor(int* a, int n) {
    int* mayor = a;
    for (int* p = a + 1; p < a + n; p++)
        if (*p > *mayor) mayor = p;
    return mayor;
}
int* m = buscarMayor(notas, 4);

¿Para qué sirve un puntero a puntero?

Para que una función cambie hacia dónde apunta un puntero de main().

void marcarDestacado(int** destacado, int* cant, int pos) {
    *destacado = cant + (pos - 1);
}

int* destacado = nullptr;
marcarDestacado(&destacado, cant, 2);
// ahora destacado apunta a cant[1]

Con int* la función solo cambia el dato. Con int** cambia el puntero mismo.

Errores comunes con punteros

El compilador no siempre los detecta. Abra cada caso para ver qué pasa.

Desreferenciar nullptr

*p cuando p es nullptr.

Segmentation fault el programa se detiene

Puntero sin inicializar

int* p; *p = 5; apunta a cualquier lugar.

warning: 'p' is used uninitialized

Salirse del arreglo

*(p + 4) en un arreglo de 4 elementos.

Lee memoria ajena. Vea la próxima lámina.

Confundir * y &

Pasar n cuando la función espera &n.

error: invalid conversion from 'int' to 'int*'

Herramienta: AddressSanitizer

Compile el mismo error de dos maneras y compare lo que le dice cada una.

int notas[4] = {90, 85, 78, 92};
int* p = notas;
return *(p + 4);   // fuera del arreglo

AddressSanitizer está en g++ de Linux y macOS. En Windows, use OnlineGDB o WSL para esta prueba.

Conexión con la programación orientada a objetos

Los punteros son la base de lo que viene en las Unidades H e I.

this

Dentro de una clase, this es un puntero al objeto que ejecuta el método.

new y delete

Los objetos creados mientras el programa corre se manejan con punteros.

Polimorfismo

Un puntero a la clase base puede señalar a un objeto de una clase derivada.

Repaso rápido

Discuta la respuesta antes de revelarla.

1. Si int* p = &n; ¿qué diferencia hay entre p y *p?

p es la dirección de n; *p es el valor guardado en n.

2. Un int ocupa 4 bytes. Si p vale 0x1000, ¿cuánto vale p + 3?

0x100C: 0x1000 + 3 × 4 bytes = 0x1000 + 12.

3. ¿Por qué una función que recibe un arreglo necesita también su tamaño?

Porque solo recibe la dirección del primer elemento; no sabe dónde termina.

4. ¿Qué necesita una función para cambiar a dónde apunta un puntero de main()?

Recibir un puntero a puntero (int**) y que main() le pase &ptr.
