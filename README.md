# TESI 2105 – Programación Orientada a Objetos

Presentaciones interactivas y laboratorios del curso TESI 2105, Instituto Tecnológico de Puerto Rico, Recinto de Manatí.
Prof. Eduardo O. De Jesús Arroyo · Primer semestre 2026-2027.

Página del curso: https://oneill162.github.io/tesi2105-poo/

## Contenido

| Archivo o carpeta | Qué es |
|---|---|
| `index.html` | Portada del curso con las 15 unidades |
| `unidadA.html` | Unidad A: Introducción (presentación interactiva) |
| `unidadE.html` | Unidad E: Punteros (presentación interactiva) |
| `assets/deck.css`, `assets/deck.js` | Motor común de las presentaciones: escala, transiciones, barra de navegación, índice, temporizador, paso a paso |
| `assets/fonts/` | Schibsted Grotesk y JetBrains Mono (licencia SIL OFL), incluidas para no depender de servicios externos |
| `presentaciones/` | Presentaciones en PDF |
| `laboratorios/` | Guías y código base de los laboratorios |

## Uso en clase

Flechas o barra espaciadora para avanzar, **I** abre el índice, **F** pone pantalla completa. `#12` al final del enlace abre la lámina 12.

Para OrbundSIS:

```html
<iframe src="https://oneill162.github.io/tesi2105-poo/unidadA.html" style="width:100%; aspect-ratio:16/9; border:0;" allow="fullscreen" allowfullscreen title="TESI 2105 – Unidad A: Introducción"></iframe>
```

Las claves y hojas de respuestas **no** se publican en este repositorio.
