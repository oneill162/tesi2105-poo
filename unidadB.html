Una variable es un dato con nombre

Guarda un valor que puede cambiar mientras el programa corre. Toda variable tiene un tipo, un nombre y un valor, y vive en una dirección de memoria (la Unidad E se dedica a eso).

cantidadnombre

En el recibo, «Café con leche × 2» es la variable cantidad con valor 2. Si el cliente pide otro, el valor cambia a 3; el nombre y el tipo no.

C++ distingue mayúsculas de minúsculas: cantidad, Cantidad y CANTIDAD son tres variables distintas.

Declarar, asignar e inicializar

int cantidad;            // declarar
cantidad = 2;            // asignar
int vasos = 3;           // inicializar
cantidad = cantidad + 1; // cambiar

Las reglas

  • Letras, dígitos y _
  • No empieza con dígito
  • Sin espacios ni símbolos
  • No puede ser una palabra reservada
  • Por costumbre: precioTotal para variables, IVU para constantes

Una constante no cambia

const double IVU = 0.115;
IVU = 0.12;
error: assignment of read-only variable 'IVU'

Con const, el compilador impide que el valor cambie por error. El IVU de Puerto Rico es 11.5 % para todas las ventas del programa.

Cambiar de tipo tiene consecuencias

  

    

      
double nota = 69.8;
int n = (int)nota;            // 69: corta
int suma = 245;
suma / 3                      // 81
static_cast<double>(suma) / 3  // 81.6667

      
Pasar de double a int no redondea: corta los decimales. static_cast es la forma moderna y visible de convertir.

    

    

      
Un char es un número

      
      
65

      
(int)'A' es 65, su código ASCII. Por eso 'a' − 'A' da 32.

    

  






  
Cuando el número no cabe

  

    

      
int x = INT_MAX;   // 2147483647
x = x + 1;
cout << x;

      
-2147483648
runtime error: signed integer overflow:
2147483647 + 1 cannot be represented in type 'int'

      
Sin avisar, el número da la vuelta. El mensaje rojo solo aparece compilando con -fsanitize=undefined.

    

    

      
Pasó en el mundo real

      
1996, cohete Ariane 5. Un número decimal de 64 bits se convirtió a un entero de 16 bits que no lo podía contener. El cohete se destruyó 37 segundos después del despegue.

      
2014, YouTube. «Gangnam Style» superó 2,147,483,647 vistas, el máximo de un int de 32 bits. YouTube tuvo que cambiar el contador a 64 bits.

Todo junto: el programa del recibo

  

    

      
const double IVU = 0.115;
int subtotal = 0;
for (int i = 0; i < 3; i++)
    subtotal += pedido[i].precio * pedido[i].cantidad;
int ivu    = static_cast<int>(subtotal * IVU + 0.5);
int total  = subtotal + ivu;
int cambio = 1000 - total;
cout << "Billetes de $1: " << cambio / 100;
cambio %= 100;
cout << "Monedas de 25: " << cambio / 25;

Lo que se lleva de esta unidad

  

    
Variables y constantes
Tipo, nombre y valor. Nombres válidos y claros. const para lo que no cambia.

    
Operadores
Entre enteros, / corta los decimales y % da el residuo. a++ no es ++a. Los paréntesis deciden el orden.

    
Tipos
Cada tipo tiene un tamaño y un límite. Convertir corta. Un pedido completo se guarda en un struct.
