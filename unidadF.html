Una función recibe el arreglo original

  
Un int llega como copia (Unidad D); un arreglo llega como dirección (Unidad E).

  

    

      
void reponer(int a[], int n) {
    for (int i = 0; i < n; i++)
        if (a[i] == 0) a[i] = 10;
}
int main() {
    int stock[5] = {8, 3, 0, 5, 2};
    reponer(stock, 5);      // se pasa el tamaño
    cout << stock[2];      // imprime 10
}

      

    

    

      
stock en main

      

      
El espacio 2 está en 0.

      
Por eso el tamaño va aparte: sizeof(a) dentro de reponer da 8, el de un puntero, y g++ avisa:

      
warning: 'sizeof' on array function parameter 'a' will return size of 'int*'
[-Wsizeof-array-argument]

Tres errores que se repiten

  

    

    

      
char codigo[2] = "B2";
error: initializer-string for 'char [2]' is too long
[-fpermissive]

      
"B2" ocupa 3 bytes: 'B', '2' y '\0'.
Use char codigo[3], o mejor char codigo[] = "B2"; para que el compilador cuente.

      
char a[] = "B2", b[] = "B2";
cout << (a == b);               // 0
cout << (strcmp(a, b) == 0);   // 1, con <cstring>
warning: comparison between two arrays [-Warray-compare]

      
Con arreglos, == compara direcciones, no el texto.
Use strcmp de <cstring>, o string, donde == sí compara el contenido.

      
string a, b;
cin >> a;             // escribe: Agua fria
cin.ignore(1000, '\n');
getline(cin, b);      // escribe: Agua fria
a = [Agua]
b = [Agua fria]

      
cin >> se detiene en el primer espacio.
Para leer una línea completa, use getline. Si antes hubo un cin >>, cin.ignore descarta el Enter que quedó pendiente.

Lo que se lleva de esta unidad

  

    
Arreglos
Tamaño fijo, índices del 0 al n − 1. Nada impide salirse: el programa lo tiene que evitar.

    
Con funciones
El arreglo llega como dirección y la función cambia el original. El tamaño se pasa aparte.

    
Matrices
[fila][columna], guardadas fila tras fila. Se recorren con dos for anidados.

    
Cadenas
char[] termina en '\0'. string sabe su largo y se compara con ==.
