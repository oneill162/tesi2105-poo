Una función crea tres cuentas: a, b y c. ¿En qué orden se destruyen?

Las tres son variables locales. Cuando la función termina, dejan de existir y corre el destructor de cada una.

a, b, cen el mismo orden en que se crearon
c, b, aen orden inverso
En orden inverso: lo último que se construyó es lo primero que se destruye, como una pila de platos. La lámina que sigue lo muestra línea por línea.

El destructor corre solo y en orden inverso

Cinco mensajes de g++ y cómo arreglarlos

class Cuenta {    double saldo = 0.0; public:    void depositar(double monto) { saldo += monto; }}
error: expected ';' after class definition

La llave que cierra la clase lleva punto y coma.

g++ da el error en la línea de la llave que cierra la clase. El arreglo: };

int main() {    Cuenta a;    a.depositar(500.00);    // por la ventanilla    a.saldo = 1000000;      // directo a la caja    return 0;}
error: 'double Cuenta::saldo' is private within this context note: declared private here

main intenta escribir en un dato privado.

Use una función pública de la clase. Si no existe la operación que hace falta, se añade a la clase; el dato no se hace público.

bool depositar(double monto) {    saldo += monto;    return true;}
error: 'saldo' was not declared in this scope

La definición no dice de qué clase es la función.

Falta Cuenta:: antes del nombre. Sin eso, es una función suelta que no conoce a saldo.

Cuenta a(1001, "Marta", 500.00);Cuenta c;
error: no matching function for call to 'Cuenta::Cuenta()'

La clase solo tiene un constructor con parámetros, y Cuenta c; no le da ninguno.

Cree la cuenta con sus datos, o añada a la clase un constructor por omisión (sin parámetros).

double consultarSaldo() const {    saldo -= 1.00;    return saldo;}
error: assignment of member 'Cuenta::saldo' in read-only object

Una función const intenta cambiar el objeto.

Si solo debe leer, sobra la línea que modifica. Si de verdad debe cambiar el saldo, no puede llevar const.

Lo que se lleva de esta unidad

Encapsulación y modularidad

Los datos van private y se llega a ellos por funciones public. Cada clase es una pieza que se cambia sin tocar las demás.

Clase y objeto

La clase es el molde; cada objeto tiene sus propios datos. La clase termina en };

Miembros

Se declaran en la clase y se definen con Cuenta::. const promete no cambiar el objeto; static es uno para toda la clase.

Constructor y destructor

El constructor deja el objeto listo y válido. El destructor corre solo, en orden inverso, y devuelve lo que se pidió.

Sobrecarga

Mismo nombre, parámetros distintos. Un operador es una función: a += 150.00 llama a operator+=.

Hacia la Unidad I

Una cuenta de ahorros y una cuenta corriente comparten casi todo. La herencia permite escribir lo común una sola vez.
