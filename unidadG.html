Declaración de estructuras

Primero se diseña la ficha en blanco: qué campos tiene y de qué tipo es cada uno.

struct Fecha {
    int dia, mes, anio;
};

struct crea un tipo nuevo

Pulse cada parte para verla en el código.

struct Laptop {    string etiqueta;    string marca;    int    ram;    bool   prestada;    Fecha  devolver;};

Llenar la ficha: dos maneras

// 1. Con llaves, en el orden de los miembros
Laptop a = {"BIB-01", "Dell", 8, false, {0, 0, 0}};

// 2. Miembro a miembro
Laptop b;
b.etiqueta = "BIB-02";
b.marca    = "HP";
b.ram      = 16;
b.prestada = true;
b.devolver = {10, 11, 2026};
cout << b.devolver.dia << "/" << b.devolver.mes ... 10/11/2026

Laptop es el molde; a y b son dos fichas llenas, cada una con sus propios valores.

El orden de los miembros cambia el tamaño

char + int + double suman 13 bytes, pero el compilador alinea cada miembro y deja huecos de relleno. Compare los dos órdenes.

sizeof

Medido con g++ 13.3 en Linux de 64 bits: sizeof(A) = 16 y sizeof(B) = 24. Las rayas son relleno: memoria que nadie usa.

Acceso a miembros

El punto lee un campo de la ficha. La flecha hace lo mismo cuando lo que se tiene es un puntero.

b.ram
p->ram

variable.miembro

Escoja una expresión y vea qué campo de la ficha lee.

p->miembro es (*p).miembro

Laptop* p = &b;
cout << p->marca;      // HP
cout << (*p).ram;      // 16
p->prestada = false;   // cambia b

Los paréntesis de (*p).ram hacen falta porque el punto se evalúa antes que el *. La flecha evita escribirlos.

Si se usa el punto con un puntero, g++ lo dice y hasta sugiere la corrección:

p.ram = 8;
error: request for member 'ram' in 'p', which is of pointer type 'Laptop*' (maybe you meant to use '->' ?)

En el Laboratorio G, buscar devuelve un Laptop* y prestar usa la flecha.

Se copian enteras; no se comparan con ==

Laptop c = a;     // copia todos los miembros
c.ram = 32;
cout << a.ram << " " << c.ram;
8 32

La asignación copia la ficha completa.

c es otra ficha: cambiarla no afecta a a. Así funciona el swap(inv[0], inv[4]) del principio.

void posponer(Fecha f)     { f.dia += 7; }
void posponerRef(Fecha& f) { f.dia += 7; }
Fecha d{3, 11, 2026};
posponer(d);    cout << d.dia;   // 3
posponerRef(d); cout << d.dia;   // 10

Igual que con un int: por valor llega una copia.

Para cambiar el original, por referencia. Para solo leer una estructura grande sin copiarla, const Laptop&.

Fecha a{1, 2, 3}, b{1, 2, 3};
if (a == b) ...
error: no match for 'operator==' (operand types are 'Fecha' and 'Fecha')

C++ no sabe qué significa que dos fichas sean iguales.

Se comparan los miembros uno a uno, o se le enseña con la sobrecarga de operadores de la Unidad H.

lista[i].miembro

Uniones

Un solo campo en la ficha que guarda una cosa u otra, nunca las dos a la vez.

union Dato {
    int    entero;
    double real;
    char   letra;
};

Una unión guarda un miembro a la vez

Todos empiezan en el mismo byte. La unión mide lo que mide su miembro más grande: sizeof(Dato) = 8. Escriba en cada uno.

entero
real
letra

Un enum dice qué miembro es el válido

enum TipoUsuario { ESTUDIANTE, EMPLEADO };
union Identificacion {
    int  numEstudiante;   // 84231
    char empleado[8];     // "E-0457"
};
struct Prestamo {
    TipoUsuario    tipo;  // la etiqueta
    Identificacion id;
    Fecha          devolver;
};
if (p.tipo == ESTUDIANTE)
    cout << p.id.numEstudiante;
else
    cout << p.id.empleado;
Estudiante 84231 Empleado E-0457

Quien tiene la laptop es un estudiante o un empleado. La etiqueta tipo evita leer el miembro equivocado.

En C++17 existe std::variant, que lleva la etiqueta por sí sola.

Cuatro errores que se repiten

struct Fecha { int dia, mes, anio; }
int main() { ... }
error: expected ';' after struct definition

La llave que cierra una struct lleva punto y coma.

Es el error más común, y g++ lo dice tal cual.

union U { int n; string s; };
U u;
error: use of deleted function 'U::U()' error: union member 'U::s' with non-trivial 'std::basic_string…'

Una unión no sabe cuál de sus miembros construir o destruir.

Por eso Identificacion usa char empleado[8] y no string.

x.real = 2.5;
cout << x.entero;   // ¿?

Compila, pero es comportamiento indefinido: el resultado no significa nada.

Solo es válido el último miembro que se escribió. Siempre lleve una etiqueta que lo diga.

Laptop* p = &b;
p.ram = 8;
error: request for member 'ram' in 'p', which is of pointer type 'Laptop*' (maybe you meant to use '->' ?)

Con un puntero, la flecha.

p->ram = 8; o (*p).ram = 8;

¿Cuándo una unión y no una estructura?

Piensen en la ficha de préstamo: ¿hace falta guardar el número de estudiante y el código de empleado a la vez?

structguarda todos los miembros a la vez
unionguarda uno a la vezunion, cuando los datos se excluyen entre sí y la memoria importa; si no, struct (o std::variant)

Lo que se lleva de esta unidad

struct

Un tipo nuevo con miembros de distintos tipos. La llave de cierre lleva ;.

Acceso

Punto con una variable, flecha con un puntero. Se copian enteras; no se comparan con ==.

union

Todos los miembros en el mismo lugar: uno válido a la vez, y una etiqueta que diga cuál.

Hacia las clases

En C++, una struct es una clase cuyos miembros son públicos por omisión. En la Unidad H se le añaden funciones.
