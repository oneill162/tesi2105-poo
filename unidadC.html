Tres formas de recorrer un programa

El recinto está en la PR-2, kilómetro 47.3. Un programa se recorre como esa carretera.

Secuenciales

Kilómetro tras kilómetro: una instrucción después de otra, sin saltarse ninguna.

Selectivas

Las salidas: según una condición, el programa toma un camino u otro.

Repetitivas

La rotonda: dar vueltas mientras se cumpla una condición, y salir cuando no.

SALIDA2

Estructuras selectivas

Según una condición, el programa toma un camino u otro.

if: tomar la salida solo si se cumple

if

if (nota >= 70) {
    cout << "Aprobado";
}

Si la condición es falsa, el programa sigue de largo.

Operador ternario

cout << (nota >= 70 ? "Aprobado" : "No aprobado");

if-else

if (nota >= 70) {
    cout << "Aprobado";
} else {
    cout << "No aprobado";
}

Uno de los dos caminos se toma siempre, nunca los dos.

Varias salidas: la cadena else if

double nota;  cin >> nota;
if (nota >= 90)      letra = 'A';
else if (nota >= 80) letra = 'B';
else if (nota >= 70) letra = 'C';
else if (nota >= 60) letra = 'D';
else                 letra = 'F';

Tres errores que compilan

  
Los tres programas corren, pero hacen otra cosa. g++ con -Wall -Wextra avisa en los tres.

  

    

    

      
int x = 3;
if (x = 5)
    cout << "cinco";
cinco
warning: suggest parentheses around assignment used as truth value

      
x = 5 no compara: asigna.
x pasa a valer 5, que cuenta como verdadero, y el if se cumple siempre. Para comparar se usa ==.

      
int nota = 40;
if (nota >= 70);
cout << "Aprobado";
Aprobado
warning: suggest braces around empty body in an 'if' statement

      
El ; termina el if ahí mismo.
El if controla una instrucción vacía, y el cout se ejecuta siempre. Un estudiante con 40 sale «Aprobado».

      
if (nota >= 70)
    cout << "Aprobado ";
    cout << "Felicidades";
Felicidades
warning: this 'if' clause does not guard...

      
La sangría no agrupa: las llaves sí.
Sin llaves, el if controla solo la primera línea. «Felicidades» sale aunque la nota sea 40. Use llaves siempre.

break sale de la rotonda; continue da otra vuelta

  
Buscamos la primera nota menor de 60. Un −1 es una nota que falta: continue la salta. Con g++ el programa imprime «85 92 en 3».

  

    

      

      

      

    

    
for (int i = 0; i < 6; i++) {
    if (notas[i] < 0)
        continue;
    if (notas[i] < 60) {
        cout << "en " << i;
        break;
    }
    cout << notas[i] << " ";
}

  






  
Un ciclo dentro de otro

  

    

      
for (int f = 1; f <= 3; f++) {
    for (int c = 1; c <= 4; c++) {
        cout << f * c << "\t";
    }
    cout << endl;
}

      

      
El ciclo de afuera da 3 vueltas; el de adentro, 4 por cada una: 12 en total.

    

    

  






  
La rotonda sin salida

  

    

      
for (int i = 0; i < 10; i--) {
    // i baja: 0, -1, -2...
    // en la práctica no termina
}

      
int k = 10;
while (k > 0) {
    cout << k;
    // falta k--
}

    

    

      
Un ciclo cuya condición nunca se vuelve falsa no termina.

      
Las tres causas típicas: la variable no cambia dentro del ciclo, cambia en la dirección equivocada, o la condición está mal escrita.

      
Si le pasa en clase, detenga el programa con Ctrl + C en la terminal.

Lo que se lleva de esta unidad

  
  

    
Secuenciales
Arriba hacia abajo, sin saltos.
El orden de las líneas cambia el resultado.

    
Selectivas
else if para rangos; switch con break para valores exactos.
Llaves siempre. == compara; = asigna.

    
Repetitivas
for, vueltas conocidas; while, puede no entrar; do-while, al menos una.
Toda rotonda necesita salida.
